## 制作ドキュメント

### 何を作ろうと思ったか

日本語学習をサポートするWebアプリを作りました。

単語や動詞を入力すると、意味だけでなく、動詞の活用、文法的な使い方、会話形式の例文を確認できるツールです。  
普通の辞書のように意味だけを見るのではなく、「実際の会話でどう使うか」までイメージできるものを目指しました。

### なぜか

自分が日本語を学習する中で、動詞の使い方に不便を感じていたからです。

中国語には、日本語のような細かい動詞変形の感覚があまりありません。  
例えば日本語では、「食べる」「食べた」「食べない」「食べている」「食べられる」のように、文法や場面によって形が変わります。  
また、「ドアが開く」と「ドアを開ける」のような自動詞・他動詞の違いも、中国語話者にとっては分かりにくい部分だと感じました。

もう一つの理由は、単語を覚えても、実際の口語場面でどう使うのか分からないことが多かったからです。  
N1の単語を覚えていても、日常会話の中で自然に使えるとは限りません。

市販の辞書や学習サイトでは、一文だけの例文が多いですが、実際の会話では相手とのやり取りの中で言葉を使います。  
そのため、単語や文法を調べたときに、会話形式の例文も一緒に見られるツールがあれば、使用場面をイメージしやすくなると考えました。

### 生成AIとのやり取り

制作では、生成AIを使ってアイデア整理、UI作成、コード生成、例文作成を行いました。

最初は、「日本語学習者向けに、単語や動詞を入力すると意味・活用・例文を表示するWebアプリを作りたい」と伝えました。  
その後、自分が学習中に感じていた課題を追加で説明しました。

特に意識して伝えたのは、以下の点です。

- 中国語話者にとって、日本語の動詞変形が分かりにくいこと
- 自動詞と他動詞の違いを理解しづらいこと
- 一文だけの例文では、実際の会話場面を想像しにくいこと
- 単語を調べたときに、口語での使い方も一緒に確認したいこと
- 学習ツールとして、見た目も少し楽しくしたいこと

生成AIには、まずHTML/CSS/JavaScriptで動く基本構成を作ってもらいました。  
その後、動詞タイプの判定、活用表、会話例、中国語・英語の翻訳、自動詞・他動詞ペア、コピー機能などを少しずつ追加しました。

一度に完成形を作るのではなく、まず小さく動くものを作り、そこから機能を足していく形で進めました。

### 詰まったところとどう乗り越えたか

一番詰まったところは、生成AI API Keyの接続部分です。

最初は、入力された単語に応じてAIがリアルタイムで会話例を生成する形にしたいと考えていました。  
しかし、API KeyをHTMLやJavaScriptに直接書くと、GitHubで公開したときにキーが見えてしまうリスクがあります。

そのため、今回はAPI接続を前提にしすぎず、まずは静的なHTML/CSS/JavaScriptだけで動く形にしました。

優先した基本機能は以下です。

- 単語検索
- 動詞活用の表示
- 中国語・英語の意味表示
- 会話例の表示
- 自動詞・他動詞ペアの表示
- コピー機能
- ブラウザだけで動作すること

まずはローカルで動くプロトタイプとして完成させ、今後フィードバックをもらいながら改善する方針にしました。

### 次にやるなら何を変えるか

次に作るなら、オンライン版として公開し、より多くの単語に対応できるようにしたいです。

現在は、あらかじめ用意した単語や例文を中心に表示しています。  
今後はバックエンドを用意してAPI Keyを安全に管理し、ユーザーが入力した単語に対して、意味・文法・活用・会話例を生成できるようにしたいです。

改善したい点は以下です。

- すべての単語に対応できるようにする
- 動詞だけでなく、名詞・形容詞・副詞にも対応する
- 文法項目からも検索できるようにする
- 例文をユーザーの日本語レベルに合わせて調整する
- 会話例をより自然な口語表現にする
- お気に入り単語や学習履歴を保存できるようにする
- スマートフォンでもさらに使いやすくする

まずは基本機能を完成させ、実際に使ってもらいながら改善し、その後オンライン版として広げていきたいです。
